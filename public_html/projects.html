FindARescue.ie (opens in a new tab)

Live and growing

FindARescue.ie (opens in a new tab) is a directory of animal rescue and welfare organisations across Ireland. The goal of FindARescue.ie is to make it as easy as possible for people to find, support, and connect with Irish animal rescue organisations.

Key features:

  • Details of over 180 animal welfare organisations, gathered manually because the publicly available data is too sparse for AI to collect reliably.
  • Keyword search, plus location and animal-type filters.
  • An interactive map to find your nearest rescue.
  • A companion Instagram account (@findarescue.ie) highlighting individual rescues across Ireland.
  • An Irish-language version of the site, translated by volunteers. See the Translation Hub project below.
  • Promotional cards, which can be found on noticeboards around Ireland.
Visit FindARescue.ie (opens in a new tab) @findarescue.ie on Instagram (opens in a new tab)

Translation Hub

Live and growing

I built the translation hub as a simple solution for crowdsourcing human translations of written content. The hub uses the translation text file from a website, and enables human translators to view, add, accept, or reject translations. The hub helps with the iterative translation of a website, where the first version uses AI-generated translation, and then human experts can confirm or correct those translations. The example above shows the translation hub used to translate FindARescue.ie into Irish.

Key features:

  • A list of English text for translation, with AI-suggested translations.
  • Add, accept, or reject translations.
  • A note option to discuss translations.
  • Export all accepted translations.
